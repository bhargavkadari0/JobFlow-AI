# JobFlow AI 🚀

### AI-Powered Job Application Tracking & Interview Preparation Platform

JobFlow AI is a full-stack web application designed to help job seekers
organize their job applications, track recruitment progress, analyze job
descriptions using AI, and prepare for interviews.

The platform combines job application management with AI-powered career
preparation tools in one place.

## ✨ Features

- **User Authentication:** Register and log in securely.
- **Job Application Tracking:** Add, manage, and monitor job applications.
- **Application Dashboard:** View application statistics and progress.
- **Application Management:** Track individual applications and their details.
- **AI Job Analysis:** Analyze job descriptions using Gemini AI.
- **AI Interview Preparation:** Generate interview preparation content.
- **Difficulty Levels:** Prepare at Beginner, Intermediate, and Advanced levels.
- **Interview Answer Evaluation:** Get AI-assisted feedback on interview answers.
- **Application Pipeline:** Organize applications by their current status.
